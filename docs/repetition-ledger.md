# Seven Gates Research: Repetition Ledger and Corrections Record

Required by sections 6.4, 6.5 and 16.4 of `docs/editorial-standard.md`. This file is the single record. The table that used to sit inside the `seven-gates-longform` skill now lives here.

## How to use it

- **Before drafting (workflow step 8):** read the last 20 entries and the permanent register. Choose an entry route, shape, hero concept and closing cadence that none of them used recently.
- **Before publishing (workflow step 10):** check the draft's anecdotes, quotations, cultural guests, historical episodes, metaphor families and memorable phrases against this file. Then add the article's own entry, in the same commit as the article. Gate question G8 is a yes only when both are done.
- **Rolling window:** the last 20 published pieces.
- **Permanent register:** quotations, proverbs and retired jokes stay blocked whatever the window says.
- Record what the article actually contains. Do not paraphrase a quotation into something the article did not say.
- Newest entry first.
